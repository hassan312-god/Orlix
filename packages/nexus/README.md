# @orlix/nexus

Moteur d'orchestration d'agents IA. Cette implémentation expose un orchestrateur en mémoire qui séquence les agents et diffuse les événements.

## Démarrage
```bash
pnpm install
pnpm --filter @orlix/nexus dev
```

## Tests
```bash
pnpm --filter @orlix/nexus test
```

## Lint
```bash
pnpm --filter @orlix/nexus lint
```
