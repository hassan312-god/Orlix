# @orlix/types

Types partagés pour l'écosystème Orlix. Ils centralisent les schémas Zod utilisés par l'API, l'Admin et le Studio.

## Démarrage
```bash
pnpm install
pnpm --filter @orlix/types dev
```

## Tests
```bash
pnpm --filter @orlix/types test
```

## Lint
```bash
pnpm --filter @orlix/types lint
```
