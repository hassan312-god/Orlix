# Orlix Admin

Dashboard Next.js 14 pour piloter les projets Orlix.

## Lancer le projet
```bash
pnpm install
pnpm --filter @orlix/admin dev
```

## Build
```bash
pnpm --filter @orlix/admin build
```

## Tests unitaires
```bash
pnpm --filter @orlix/admin test
```

## Lint
```bash
pnpm --filter @orlix/admin lint
```
