# Orlix Studio

Application desktop Tauri + React pour travailler hors-ligne et synchroniser avec Orlix Core.

## Démarrage web
```bash
pnpm install
pnpm --filter @orlix/studio dev
```

## Démarrage desktop
```bash
pnpm --filter @orlix/studio tauri:dev
```

## Build desktop
```bash
pnpm --filter @orlix/studio tauri:build
```

## Tests
```bash
pnpm --filter @orlix/studio test
```
